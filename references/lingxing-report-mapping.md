# 领星ERP广告报告字段映射

本文件基于用户提供的五份领星导出样本整理。系统继续输出既有 `StandardRow` 结构，因此分析引擎与前端界面无需变更。

| 领星文件 | 识别特征 | 系统报表类型 | 关键字段映射 |
|---|---|---|---|
| `产品表现.xlsx` | `负责人`、`Sessions-Total`、`广告花费` | `business_report` | `ASIN`、`MSKU`、`Sessions-Total`、`PV-Total`、`CVR`、`销量`、`销售额`、`Buybox赢得率`、`负责人` |
| `广告活动报告-汇总.xlsx` | `广告活动`、`预算` | `campaign_report` | `广告组合`、`广告活动`、`有效状态`、`预算`、`曝光量`、`点击`、`花费-本币`、`广告销售额-本币`、`广告订单` |
| `商品投放报告-汇总.xlsx` | `投放`，且不含`用户搜索词`和`广告名称` | `targeting_report` | `广告活动`、`广告组`、`投放`、`有效状态`、`竞价-本币`、核心广告绩效字段 |
| `用户搜索词报告-汇总.xlsx` | `用户搜索词` | `search_term_report` | `广告组合`、`广告活动`、`广告组`、`关键词`、`匹配方式`、`投放`、`用户搜索词`、核心广告绩效字段 |
| `广告（推广的商品）报告-汇总.xlsx` | `广告名称`、`ASIN`、`广告活动` | `advertised_product_report` | `广告活动`、`广告组`、`广告名称`、`ASIN`、`MSKU`、`广告有效状态`、核心广告绩效字段 |

## 数值处理

金额字段使用 `*-本币` 列；百分比字段支持 Excel 小数值和 `38.54%` 文本。`--`、空值和“有花费无销售额”等非数值文本将被安全识别为缺失值，再由既有指标推导逻辑计算可用指标。
